Get your Spotify listening data

To see your actual listening time — including your most-listened month, day, and week — request Spotify's Extended Streaming History. The regular account-data download only includes about the past year; Extended Streaming History covers the lifetime of your account.

01 / Request your data

  1. Open Spotify's Account Privacy page in a browser and sign in.
  2. Find the Download your data section.
  3. Select Extended streaming history. You do not need the regular Account data package for this tracker.
  4. Press Request data. If Spotify asks you to confirm by email, follow the confirmation link.

02 / Download the export

  1. Wait for Spotify's email saying your data is ready. Spotify says preparing a data copy can take up to 30 days.
  2. Use the link in the email to download the ZIP file to your device.
  3. Keep the ZIP file intact — you can upload it directly here. You can also extract it and select the individual Streaming_History_Audio JSON files.

03 / Import it into this tracker

  1. Return to the Upload My Data tab.
  2. Drop the Spotify ZIP file into the upload area, or click the area and choose the ZIP. If you extracted the download, select all of the Streaming_History_Audio JSON files.
  3. After processing, choose All Time or set a custom date range.
  4. Open Listening Patterns above your results to see your busiest month, day, and week in that date range.

Privacy: This tracker reads and processes the files in your browser. The export is not sent to a server by this page. Your Spotify download contains personal listening information, so keep the ZIP somewhere private and only upload it to services you trust.

What should I upload?

Look for files named Streaming_History_Audio_… .json inside the ZIP. Upload the ZIP itself for the easiest option, or select every matching audio-history JSON file if you extracted it. The tracker uses the timestamps and milliseconds-played values in those records to calculate listening time.
